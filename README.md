# memworld · 长程记忆文字世界

一个测量 agent 记忆的 bench：由三条规则按 seed 生成的文字世界，没有尽头。agent 要记住很久以前听到的词、人和话，才能一夜一夜地走下去。先作为 bench，之后它生成的轨迹（带有「该记什么」的精确标注）可以作为数据集。

```text
墨围裙的刀客眼皮不抬，声音压得像刀背贴骨：「要过去，先说讨⟨盘哆⟩的那位给你的那句切口。」
嗓子沙哑的寡妇拽住你的袖子，孝布擦过你手背：「去寻嗓子沙哑、白蓑衣的老鸨，把红灯笼的棺材铺掌柜给你的那句切口，原样递过去。」
```

## 快速开始

需要 [uv](https://docs.astral.sh/uv/) 和 Python 3.12+，只依赖标准库。仓库里有两个包：

- **`memworld`**：环境本身，包括世界、皮、配置。
- **`membench`**：在环境上跑 bench，包括参照 agent、跑局、统计、LLM 实测。它依赖 `memworld`，反过来不依赖。

```bash
uv sync

# 环境
uv run memworld play                                   # 自己玩（加 --llm 用 LLM 润色台词）

# bench
uv run membench demo --seed 3 --T 120                  # 看完美记忆 agent 走一局
uv run membench check                                  # 3 档难度 × 50 个 seed × 20 章，验证世界可解
uv run membench curve                                  # 只记得最近 W 步的 agent 能走多远
uv run membench notes --config config/memory.toml      # 失忆的更夫：纸条长度曲线（程序参照）
uv run membench llm --config config/memory.toml \
    --modes full,m800,m3200 --seeds 3 --T 400 --out results   # 用 LLM 实测

uv run python -m unittest discover -s tests
```

把自己的 agent 接到环境上：

```python
from memworld import World, load

world = World(load("config/memory.toml"), seed=3)    # 也可以 load(decay=2, indirect=0.5) 直接改旋钮
obs = world.reset()                                  # 给 agent 的文字；规则说明在 world.instructions
obs, done, info = world.step("走 3")                 # 或 "走 独眼的刀客"、"说 哩咯"
```

跑完用 `membench.summary(world.trace, world.chapter)` 统计。用 LLM（润色或实测）时，在项目或上一级目录的 `.env` 里写 `DEEPSEEK_API_KEY=...`，或设置同名环境变量。

## 玩法

- 动作只有两种：**走**到某人身边，对身边的人**说**一个 ⟨⟩ 里的词。每个动作算一步。
- 每个人只开口一次：初见时说他要什么，被满足时给你一样东西（一个词、一条路，或一句关于别人要什么的话），之后不再说话。
- **要的词从不直说**，只告诉你它在哪段过去里：「某人给你的那句」「讨『某人给你的那句』的那位给你的那句」……有人替别人传话，有人改主意（以最新的为准），很多章以前的词也会突然又被要到。
- **说错有代价**：明明拿到过那句切口却说错，算一次；次数用完就被抓。还没拿到就开口，对方只会让你先去拿，不算错，但白费一步。
- 目标：T 步之内走出尽可能多的章。走过的地方回不去，听过的话不会再听到第二遍。

## 设计

**世界是一串事实，每道门是一个对过去事实的查询。**

### 一条不变量

> **一个人要的一切，在你能满足他之前，都已经有人说出。**

p 要的词、p 的要求、绕着说时经过的每一件事，全都来自 p 的**祖先**：满足 p 之前必须先满足的人，包括前几章所有的必经之人。由此：

- 世界按构造可解，不需要搜索验证。
- 任何走法下，信息都一定已经交到你手里。卡住只可能是因为没记住、没想起，或者走得太慢。

### 三条规则

| 规则 | 做法 | 为什么不破坏不变量 |
|---|---|---|
| **补给** | 从出口往回长：每个被要的词，都有唯一一个给出者；给出者可以是一个人，也可以是一片区域 | 骨架本身就是依赖图 |
| **指代** | 要求里的词从不直说，而是沿一条过去的事实走过去，可以继续走，最后在某处叫出名字。六种一跳关系：「X 给你的那句」「X 要的那句」「给你 ⟨u⟩ 的那位」「讨 ⟨u⟩ 的那位」「替 X 传话的那位」「X 替他传话的那位」。要的词也可以是旧词：越常用、越近的旧词，越容易被再次要到 | 只走祖先说过的事实，且每一步在全世界唯一地指向下一个 |
| **转述** | 一个人要什么，可以由本人说，也可以由别人代说；之后还可能有人来改口，可以改不止一次，以最新的为准。改口时在边 w → p 上插入一个新的给出者（要 w，给 w′），p 改要 w′ | 代说的人只要祖先的词；改口后原有依赖一条不少，不会出现捷径；对 p 说 w 算过期 |

转述的对象总是直呼其名：不知道一句话说的是谁，就谈不上记住它。

### 旋钮

| 旋钮 | 规则 | 控制 |
|---|---|---|
| `recall` | 指代 | 一个人另要一个旧词的概率 |
| `decay` | 指代 | 旧词每被用过一次攒一份机会，k 章前的那份按 k^(−decay) 衰减。0 = 只看用过几次；越大越偏向最近 |
| `indirect` | 指代 | 在必绕的一步之外，每多绕一步的概率。多跳长度由它自然决定 |
| `relay` | 转述 | 由别人代说的概率 |
| `revise` | 转述 | 有人来改口的概率，改完还可能再改 |
| `size` | 补给 | 一片区域的骨架人数 |
| `depth` | 补给 | 区域最多嵌套几层 |
| `ramp` | — | 前 ramp 章里，上面五个记忆旋钮从 0 爬到配置值，让任何 agent 都能起步 |

另有两个运行参数：步数上限 `T`，以及说错几次被抓 `strikes`（0 = 不限）。

## 测量

### 失忆的更夫（评测协议）

> 你是更夫。每到天亮，你会忘掉这一夜的一切，只剩口袋里一张纸条，最多写 B 个字。

一夜就是一章。夜里 agent 记得这一夜的全部经过（相当于上下文），走出一章时必须决定纸条上写什么，下一夜只有这张纸条（相当于跨会话的持久记忆）。B 是唯一的协议参数，产出的是一条随 B 变化的曲线，而不是一个分数。「全记下来」只是 B 很大时的那个点，所以刷不爆。

### 主指标：首答正确率，分当夜与隔夜

- **首答**：每道门第一次正式回答（排除还没拿到答案就开口的情况）。之后的尝试可能是在乱猜，不算。
- **当夜**：答案是这一夜听到的。反映推理和绑定能力，不受记忆方式影响。
- **隔夜**：答案是之前的夜里听到的。反映记忆。

同一个模型分别用「全上下文」和「失忆」两种方式跑，当夜正确率应当相同，隔夜之差就是记忆的代价，模型本身的推理强弱被约掉。走出几章作为次要指标：它会被 agent 最弱的那项能力拖住，可能是推理，也可能是策略。

### 参照 agent

| agent | 作用 |
|---|---|
| `Oracle` | 完美记忆，只用听到的内容。验证世界可解，也是一切曲线的天花板 |
| `Window(W)` | 只记得最近 W 步，相当于上下文窗口有限 |
| `Memento(B, policy)` | 失忆的更夫，程序版。`hindsight` 偷看未来，只记以后真会用到的事实，是不知道未来的方法够不到的上界；`need` 按「越常用、越近越重要」记；`recent` 只记最近的 |
| `LLMAgent` | 接 LLM。三种跑法：全上下文、失忆（纸条 B 字）、开卷（直接给它完美记忆整理好的事实清单） |

生成器知道未来会用到哪些事实，所以「这一夜结束时最少该记住什么」可以精确算出来，既能作为理论下界，也能作为训练数据的标签。

## 实验与发现

以下用 DeepSeek（`deepseek-chat`）和程序参照跑出。每一轮的失败案例都改变了设计：

1. **答案曾经就写在要求里。** 「把⟨巴米⟩带来给我」等于把答案说了出来，LLM 照念就过，全上下文的 LLM 甚至比完美记忆走得还远。改为要求里只说答案在哪段过去，从不说答案本身。
2. **旧词曾经总是直说。** 给旧词措辞时，只允许指向本章的人，于是前几章的旧词一律直说，长程记忆其实没被考到。改为前几章的必经之人也都算祖先。
3. **说错曾经几乎没有代价。** 一步的代价太小，LLM 会拿听过的词挨个去试。加上被抓，并且只在「本该知道」时才算错。还没拿到答案就开口，怎么说都不可能对，只算急躁。
4. **一开局难度就拉满，所有 LLM 都死在第一章。** 加入 `ramp` 爬坡，把推理负荷和记忆负荷分开（`config/memory.toml`）。
5. **「走出几章」被 agent 最弱的能力拖住。** 即使只绕一步，全上下文的 LLM 每答 8 次左右就会对错一次号（当夜首答正确率约 92%），大家都卡在第 2 章，记忆的差别被淹没。主指标因此改为首答正确率，分当夜与隔夜。

当前数据（记忆赛道，400 步，3 个 seed 合计）：

| 跑法 | 当夜首答 | 隔夜首答 |
|---|---|---|
| 完美记忆（程序） | 215/215 | 154/154 |
| 失忆·need·800 字（程序） | 79/80 | 26/33 |
| 失忆·need·3200 字（程序） | 193/193 | 138/140 |
| DeepSeek 全上下文 | 48/52 = 92% | 13/16 = 81% |
| DeepSeek 失忆·3200 字 | 26/28 = 93% | 3/6 |
| DeepSeek 失忆·800 字 | 28/30 = 93% | 4/5 |

当夜正确率在三种跑法下一致，说明指标按设计分开了推理与记忆。但 LLM 走得慢（400 步只走 1～2 章，完美记忆走 10 章），隔夜样本还太少，**还不能下关于 LLM 记忆的结论**。另外，DeepSeek 失忆时自己写的纸条相当像样：它会按顺序整理「谁给了什么、谁要什么」，一千字左右。

程序参照的纸条曲线（`membench notes`）显示：纸条越长，隔夜越准、走得越远；偷看未来（`hindsight`）始终明显高于不偷看的策略，这个差距就是「知道未来」的价值。`need` 与 `recent` 几乎一样，说明现在旧词的「常用」信号还很弱：多数旧词只被用过一两次，真正起作用的只有「多近」。

## 世界观与皮

世界只产生结构化事件，由「皮」变成文字。世界观只决定怎么说，不决定是什么：规则、依赖和分数都与它无关。

**世界观**是一份 TOML，例如 [settings/heishui.toml](settings/heishui.toml)。《黑水渡》讲的是一个雾锁的江湖河港：灭门案之后，你作为目击的更夫一街一街地逃，⟨⟩ 里的词在故事里是江湖切口。文件里有背景和文风、身份及其人设、命名词库、切口用字、每类事件的台词，以及六种关系各自的说法。称呼、地名、切口都是组合出来的，全局不重复，组合用尽后自动叠加或加长，所以世界可以无限长下去。

- `TemplateSkin`：按世界观的台词填写，确定、可复现，是默认的皮。
- `LLMSkin`：在模板句之上，以世界观为背景、说话人的人设为口吻改写。对绕着说的指代，把原句里拼接的部分挖成占位，只给 LLM 线索链，让它用自然的话讲出来；再让 LLM 只看改写结果做回译，还原出的线索链必须与原来一致，否则退回模板句。实测 deepseek-chat 在多跳指代上的改写和回译都不够可靠，所以目前它只适合试玩，评测请用模板皮。

## 配置

所有默认值都在 [config/default.toml](config/default.toml)，其他配置文件只写要改的项：

| 文件 | 用途 |
|---|---|
| [config/default.toml](config/default.toml) | 默认：各种难度都有一些，前 5 章爬坡 |
| [config/memory.toml](config/memory.toml) | 记忆赛道：推理负荷固定在低水平（只绕一步、少量代说、不改口），旧词多且久远，不设被抓 |
| [config/hard.toml](config/hard.toml) | 难度调高的例子 |

## 路线图

- **更长的 LLM 实测**：隔夜样本要上百个才有结论。需要更长的局，或者一个「引导模式」：世界按顺序把人带到你面前，免去探索，专测回答。
- **让「常用」成为真信号**：现在多数旧词只被用过一两次，`need` 和 `recent` 分不开。可以让同一批人跨夜反复出现，或者调高旧词的复用率，让「该记什么」有可学的结构。
- **AI 生成世界观**：按 `settings/*.toml` 的格式生成，加载时校验。
- **数据集**：导出轨迹，附上每一夜「最少该记什么」的标注。
